深度 RL

状态不再能做成表格。用神经网络估 Q 或 π。真正要吃透的是 DQN 和 PPO；其余大多是变体。LLM 对齐整棵树都长在 PPO 上。

算法怎么分家

先问两个问题，就能把常见名字放进格子里：

学价值，策略派生直接学策略
不用环境模型DQN、C51、SAC（Q 侧）REINFORCE、A2C、PPO、GRPO
用环境模型规划 / world model（学 LLM 对齐可先不管）

再问数据从哪来：on-policy 的 PPO 必须用当前 π 采样；off-policy 的 DQN 可以吃 replay。连续动作（机械臂）常用 DDPG / TD3 / SAC：actor 输出均值，critic 估 Q。生成 token 是离散大词表，走策略梯度，不走 DDPG。

DQN：Q-learning 接到网络

表格更新是

\[ Q(s,a)\leftarrow Q(s,a)+\alpha\bigl(r+\gamma\max_{a'}Q(s',a')-Q(s,a)\bigr) \]

图像或长向量状态时 \(Q\) 表爆炸，改成 \(Q_\theta(s,a)\)。直接对 TD 误差做回归会炸，因为相邻样本相关、目标跟着自己跑。两件补丁：

  • Experience replay：把 (s,a,r,s') 丢进缓冲，随机抽。打破序列相关，也让一份转移能用多次。
  • Target network：\(\max\) 那边用一套慢更新的 \(\theta^-\)。每隔 \(N\) 步 \(\theta^- \leftarrow \theta\)，否则目标每步都在动。
\[ y = r + \gamma \max_{a'} Q_{\theta^-}(s', a'), \qquad L = \bigl(y - Q_\theta(s,a)\bigr)^2 \]

\(y\) 对 \(\theta^-\) 不反传。Double DQN 再改一刀：\(\arg\max\) 用 \(\theta\)，取值用 \(\theta^-\)，减轻 \(\max\) 带来的过估计。Dueling 把 \(Q\) 拆成 \(V(s)+A(s,a)\)。这些是稳定技巧，不是新问题。

实现上就是：env.step → 写入 replay → 抽 batch → 算 y → 反传 Q 网络。CartPole 这种低维状态，几万步就能竖杆。

策略梯度

目标 \(J(\theta)=\mathbb{E}_{\tau\sim\pi_\theta}\bigl[\sum_t r_t\bigr]\)（或折扣版）。对参数求导，得到 REINFORCE：

\[ \nabla_\theta J \;\approx\; \sum_t \nabla_\theta \log \pi_\theta(a_t \mid s_t)\, G_t \]

直觉：这条轨迹回报高，就提高当时那些动作的概率；回报低就压低。\(\nabla_\theta\log\pi\) 是「怎么改网络才能让这个 \(a\) 更常被抽到」；\(G_t\) 是权重。

\(G_t\) 方差极大（整条轨迹的运气都混进来）。减掉一个不依赖 \(a\) 的 baseline 不改变期望，但能降方差。最常用 baseline 就是 \(V(s)\)，于是权重变成优势：

\[ \nabla_\theta J \;\approx\; \sum_t \nabla_\theta \log \pi_\theta(a_t \mid s_t)\, A_t \]
\[ A_t = Q(s_t,a_t) - V(s_t) \;\approx\; G_t - V(s_t) \]

A2C：一个网络出 \(\pi\)（actor），一个出 \(V\)（critic）。critic 的损失是 \(\bigl(G_t-V(s_t)\bigr)^2\) 或 TD 误差。

GAE：优势怎么估

一步 TD 优势 \(\delta_t=r_{t+1}+\gamma V(s_{t+1})-V(s_t)\)。方差小、偏大。把未来的 \(\delta\) 按 \(\lambda\) 折扣加起来，就是 GAE：

\[ A_t^{\mathrm{GAE}} = \delta_t + (\gamma\lambda)\,\delta_{t+1} + (\gamma\lambda)^2\delta_{t+2} + \cdots \]

\(\lambda=0\) 是一步 TD；\(\lambda=1\) 接近 MC。PPO / 多数 LLM RLHF 实现都用 GAE，\(\lambda\) 常见 \(0.95\)。GRPO 不训 \(V\)，所以不用 GAE，改用组内相对分数当 \(A\)。

PPO：现在的默认策略梯度

直接对 on-policy 数据做多次梯度上升，π 会一步走出采样分布，ratio 爆炸。PPO 用 clip 把每次更新钉在旧策略附近。

三件事：

  1. Importance ratio：\(r_t(\theta)=\pi_\theta(a\mid s)/\pi_{\mathrm{old}}(a\mid s)=\exp(\log\pi_\theta-\log\pi_{\mathrm{old}})\)。用旧策略采的数据，校正到新策略。
  2. Clip：ratio 限制在 \([1-\varepsilon,\,1+\varepsilon]\)，\(\varepsilon\) 常见 \(0.2\)。
  3. On-policy 小步：采一批 → 更新 \(K\) 个 epoch → 丢掉，重新采。
\[ L^{\mathrm{CLIP}}(\theta) = \min\bigl( r_t(\theta)\,A_t,\; \mathrm{clip}\bigl(r_t(\theta),\,1-\varepsilon,\,1+\varepsilon\bigr)\,A_t \bigr) \]

正优势：clip 挡住 \(r\) 涨过 \(1+\varepsilon\)，概率不能一次拉太高。负优势：clip 挡住 \(r\) 跌破 \(1-\varepsilon\)，概率不能一次砸太低。取 \(\min\) 是为了走更悲观的那个。

完整 PPO 损失通常还有两项（游戏设定；LLM 里 KL 往往另算）：

\[ L = L^{\mathrm{CLIP}} - c_v\bigl(V_\theta(s)-V^{\mathrm{targ}}\bigr)^2 + c_e\,H[\pi_\theta](s) \]
  • value loss：让 V 跟上回报，给下一轮 GAE 用。
  • entropy bonus：防止 π 过早变成 one-hot，保留探索。
LLM 对齐里的 PPO 还要加：reward model、对 SFT / ref 策略的 KL 惩罚、value model。公式变长了，ratio 和 clip 没变。GRPO 把 value 换成组内归一化，clip 还在。

一次 PPO 更新在代码里长什么样

和 CleanRL 单文件同一套骨架，不是另一套算法：

  1. 用 π_old 在环境里跑 T 步（或 N 个并行 env × T），记下 s, a, logπ_old, r, done, V。
  2. 用 GAE 从后往前扫出 \(A_t\)，再 \(R_t=A_t+V_t\) 当 value 目标。
  3. 把 A 在这一批上标准化（减均值除标准差），梯度尺度才稳。
  4. 打乱，切 minibatch，对同一批数据做 K 轮：算新 logπ → ratio → clip 损失 → 反传。
  5. 丢掉这批数据。下一轮必须重新采样。

Early stop：若平均 |r − 1| 超过约 1.5ε，说明已经走出信任域，这一批别再训了。LLM 框架里不一定有，但意思一样：on-policy 数据不能榨太狠。

常见坑

  • Reward 没归一化 / A 没标准化：梯度尺度乱跳。
  • 把 off-policy 旧数据硬塞给 PPO：ratio 爆炸，clip 挡不住系统性偏差。
  • 只看 loss 下降：clip loss 变小不代表策略变好，看 episode return 或下游任务。
  • logπ 在采样时和更新时用了不同的数值路径（半精度、不同 kernel）：ratio 的分母是脏的。LLM 后训练把这个问题放大成系统问题。
