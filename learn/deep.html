深度 RL

状态不再能做成表格。用神经网络估 Q 或 π。你真正要吃透的是 DQN 和 PPO；其余大多是变体。

DQN：把 Q-learning 接到神经网络

朴素 Q-learning：Q(s,a) ← Q + α (r + γ max Q(s',·) − Q)。状态是图像时 Q 表爆炸，改成 Q_θ(s,a)。

两个让它能训起来的技巧：

  • Experience replay：把 (s,a,r,s') 丢进缓冲，随机抽。打破序列相关。
  • Target network：max 那边用一套慢更新的 θ⁻，否则目标跟着自己跑。

读一份实现就够：cleanrl/dqn.py（大约 200 行）。先在 CartPole-v1 跑绿。

策略梯度

目标：J(θ) = E_{τ ~ π_θ}[G(τ)]。对参数求导（REINFORCE）：

∇J ≈ Σ_t  ∇ log π_θ(a_t|s_t) · G_t

直觉：某条轨迹回报高，就提高当时那些动作的概率；回报低就压低。

G_t 方差极大。换成优势 A_t（减掉 baseline / value）是所有实用算法的第一步。A2C：一边学 π，一边学 V 当 baseline。

PPO：现在的默认策略梯度

PPO（2017）几乎是游戏 RL 和 LLM RLHF 的共同祖先。记住三件事：

  1. Importance ratio：r_t(θ) = π_θ(a|s) / π_old(a|s)。用旧策略采的数据，校正到新策略。
  2. Clip：把 ratio 限制在 [1−ε, 1+ε]，防止一次更新把策略拧飞。
  3. On-policy 小步：采一批 → 更新几 epoch → 丢掉，重新采。
L = min( r·A , clip(r, 1−ε, 1+ε)·A )

正优势时 clip 防止 prob 涨太猛；负优势时防止 prob 跌太猛。

LLM 对齐里的 PPO 还要再加：value model、对 SFT 策略的 KL 惩罚、reward model。公式变长了，ratio 和 clip 没变。

连续动作（扫一眼即可）

DDPG / TD3 / SAC 处理连续控制（机械臂、MuJoCo）。学 LLM 对齐可以先跳过，知道「还有 off-policy actor-critic」就行。以后做机器人再回来。

常见坑

  • Reward 没归一化 / advantage 没标准化：梯度尺度乱跳。
  • 把 off-policy 数据硬塞给 PPO：ratio 爆炸。
  • 只看 loss 下降：PPO 的 clip loss 下降不代表策略变好，看 episode return。
  • γ、GAE λ、clip ε 乱改：先用论文默认，环境跑绿再调。
