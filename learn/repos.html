教科书和中文入门

资源形式为什么读
Sutton & Barto, RL: An Introduction 2nd 免费 PDF 定义权威。读第 1–6、13 章就够入门策略梯度。别从第 1 页线性读到附录。
datawhalechina/easy-rl · 在线蘑菇书 中文教程 + notebook 李宏毅深度 RL 课的文字整理。中文最快建立 DQN/PPO 图像。
boyu-ai/Hands-on-RL 代码课 《动手学强化学习》。每章有可跑代码，补蘑菇书习题。

课（英文，质量高）

课为什么读
OpenAI Spinning Up · openai/spinningup 最短的「术语 + 算法族谱 + 关键论文清单」。Essay 讲怎么长成 RL 研究者，值得读完。
David Silver UCL RL 经典视频。MDP、DP、MC、TD、PG 一条线讲完。配 Sutton 书。
Hugging Face Deep RL Course 有练习、有证书、接 Gymnasium / SB3。动手型。
Berkeley CS285 研究生课，覆盖 model-based、offline、robotics。第二遍再听。

代码：先读单文件，再碰框架

仓库为什么读
vwxyzjn/cleanrl · docs 每个算法一个文件。PPO/DQN/SAC 的参考实现。学算法就 clone 这个。
Farama-Foundation/Gymnasium 现在的环境标准（OpenAI Gym 的继任）。CartPole-v1 从这里来。
DLR-RM/stable-baselines3 调包跑实验。不要当第一份源码读。
thu-ml/tianshou 清华的模块化 PyTorch RL。中文社区友好。
dennybritz/reinforcement-learning Sutton 书配套 notebook，表格型方法很好。

LLM 后训练

仓库为什么读
huggingface/trl PPO/DPO/GRPO 的入门实现。先看 trainer 里 ratio 怎么写。
OpenRLHF/OpenRLHF 更接近生产的 RLHF 栈。
volcengine/verl Hybrid engine：FSDP/Megatron 训练 + vLLM rollout。看数据怎么切。
THUDM/slime Megatron + vLLM。vime 的训练底盘之一。
vllm-project/vime 框架层对齐。RL-Kernel 往它下面插算子。
RL-Align/RL-Kernel 你 fork 的上游。算子层，不是框架。
