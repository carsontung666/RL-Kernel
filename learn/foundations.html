RL 基础

先把五个对象和两个函数钉死。后面所有算法都是在估这几个量。

五个对象

名字记法一句话
状态s智能体此刻看到的世界摘要
动作a可以选的一步
奖励r环境立刻打的分，可正可负
策略π(a|s)在 s 下选 a 的分布
折扣γ ∈ [0,1)未来奖励打几折；γ=0 只看眼前

交互循环：s → a ~ π → r, s' → …。一条轨迹是 (s0,a0,r1,s1,a1,…)。

MDP

马尔可夫决策过程假设：下一步只依赖当前状态和动作，不依赖更早的历史。写成五元组 (S, A, P, R, γ)。

  • P(s'|s,a)：转移
  • R(s,a) 或 r(s,a,s')：奖励

LLM 里状态经常是「到目前为止的 token 序列」，动作是「下一个 token」。马尔可夫性靠把历史塞进上下文来凑。

回报与价值

从时刻 t 起的折扣回报：

G_t = r_{t+1} + γ r_{t+2} + γ² r_{t+3} + …
函数问的问题
状态价值 V_π(s)从 s 出发，一直跟 π，期望回报是多少
动作价值 Q_π(s,a)在 s 先做 a，之后跟 π，期望回报是多少
优势 A_π(s,a) = Q − V这个动作比「平均水平」好多少
PPO / GRPO 真正优化的是优势，不是原始奖励。奖励告诉你发生了什么；优势告诉你这个动作该被加强还是削弱。

Bellman

价值满足递归（最优时把 π 换成 max）：

V(s) = E[ r + γ V(s') ]
Q(s,a) = E[ r + γ max_{a'} Q(s',a') ]   # 最优 Q

动态规划（值迭代、策略迭代）在状态能枚举时直接解这个方程。状态一大，就改成采样 + 函数近似，那就是深度 RL。

两条家族

家族学什么代表
基于价值学 Q，策略由 Q greedy 出来Q-learning、DQN
基于策略直接参数化 π_θ，用梯度推高期望回报REINFORCE、PPO、GRPO
Actor-Criticπ 和 V 一起学A2C、PPO（有 value head 时）

语言模型几乎全是策略梯度：词表太大，Q-table 不现实；生成是序列决策，自然是 π(token | prefix)。

On-policy 和 off-policy

  • On-policy：用来学习的数据必须来自当前策略。PPO、GRPO 都是。
  • Off-policy：可以用旧策略、甚至别的策略产生的数据。DQN、DPO 的偏好对更接近后者。

On-policy 所以才有 importance ratio：π_new / π_old。LLM 训练里 π_old 的 logprob 往往是 rollout 引擎算的，π_new 是训练引擎重算的——两边不一致，ratio 就是垃圾。这是后面系统页的伏笔。
