知识怎么分层

在解决什么核心对象
表格 RL 状态能枚举时学策略 Q 表、ε-greedy、Bellman 更新

系统层 rollout 和训练对同一条序列给出对齐的 logprob fused logp、batch-invariant、确定性归约

三句定义

  • 强化学习：智能体在环境里试动作，用回报学策略。没有现成的「正确答案标签」。
  • 深度 RL：策略或价值函数是神经网络，状态可以是图像或 token 序列。
  • LLM RL：环境是「提示 + 生成」，动作是 token，奖励来自人类、裁判模型或规则。
后面几页会反复出现两个量：advantage（这个动作比平均好多少）和 importance ratio（新策略相对旧策略的概率比）。看不懂这两项时，先停在基础和深度 RL。
