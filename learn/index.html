三句定义

  • 强化学习：智能体在环境里试动作，用回报学策略。没有现成的「正确答案标签」。
  • 深度 RL：策略或价值函数是神经网络，状态可以是图像或 token 序列。
  • LLM RL：环境是「提示 + 生成」，动作是 token，奖励来自人类、裁判模型或规则。
