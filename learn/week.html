四周计划

每天 2–4 小时。四周后你应该能：手写 PPO clip 损失、讲清 GRPO 和 PPO 的差别、读懂 RL-Kernel 的 linear_logp 在算什么。

第 1 周 · 词汇和表格 RL

  1. 本 handbook 的基础页读两遍。
  2. 蘑菇书第 1–3 章，或 Sutton 第 1–4 章二选一，不要两份一起做。
  3. 跑 Q-learning notebook 或 FrozenLake。能解释 ε-greedy 和更新式。
  4. 笔记里必须出现：MDP 五元组、G、V、Q、A、on/off-policy。
验收：合上书，用一张纸画出智能体循环，并写出 Q-learning 更新。

第 2 周 · 深度 RL，只碰两个文件

  1. 读 Spinning Up intro。
  2. Clone cleanrl，先跑：
uv run python cleanrl/dqn.py --env-id CartPole-v1 --total-timesteps 50000
uv run python cleanrl/ppo.py --env-id CartPole-v1 --total-timesteps 50000
  1. 对着 ppo.py 把 ratio、clip、advantage 三处标出来。
  2. 读 PPO 论文方法节（可以跳实验）。
验收：不看论文，写出 PPO 的 clip 目标；CartPole 两条曲线都拉上去。

第 3 周 · LLM 对齐

  1. 读 InstructGPT、DPO、DeepSeekMath 三篇的方法节（论文页）。
  2. 用 TRL 跑通官方 DPO 或 GRPO 最小例子（小模型，CPU/单卡都行）。
  3. 在笔记里画：SFT → RM → PPO vs DPO vs GRPO，各需要哪些模型。
  4. 写下 old_logprob 和训练侧重算 logprob 分别由谁产生。
验收：能向别人讲清「为什么 GRPO 可以不要 value model」，以及 ratio 的分子分母从哪来。

第 4 周 · 接到 RL-Kernel

  1. 读官方文档 rl-align.github.io/RL-Kernel 的 linear_logp 和 fused logp。
  2. 在本地 clone 里跑 examples/grpo_single_gpu.py（有 GPU 再跑；没有就读代码和测试）。
  3. 读 issue #83 的 P0.3+ 一段，知道 WS1/WS2 在锁什么。
  4. 打开 tests/test_batch_invariant_logp.py，看「batch=1 vs N」怎么断言。
验收：能说出 fused linear logp 省掉的是哪块张量，以及 batch-invariant 要在哪些配置下保持不变。

环境建议

  • 第 1–2 周：任意笔记本 + CPU。
  • 第 3 周：一块能跑 1B 级模型的 GPU 更舒服；没有就只读 TRL 源码。
  • 第 4 周：和 RL-Kernel 文档一样，CUDA 源码构建需要匹配的 PyTorch wheel。
