RL 基础

先把对象、价值和更新规则钉死。后面 DQN、PPO、GRPO 都是在估这几个量，换了函数近似和采样方式而已。

五个对象

名字记法一句话
状态s智能体此刻看到的世界摘要
动作a可以选的一步
奖励r环境立刻打的分，可正可负
策略π(a|s)在 s 下选 a 的分布
折扣γ ∈ [0,1)未来奖励打几折；γ=0 只看眼前

交互循环：s → a ~ π → r, s' → …。一条轨迹是 (s₀, a₀, r₁, s₁, a₁, …)。

环境对外就是两步：reset() 给初始状态；step(a) 返回 (s', r, done)。CartPole、FrozenLake、语言模型解码，接口形状一样。

MDP

马尔可夫决策过程：下一步只依赖当前状态和动作，不依赖更早的历史。五元组 (S, A, P, R, γ)。

  • P(s'|s,a)：转移
  • R(s,a) 或 r(s,a,s')：奖励

LLM 里状态是「到目前为止的 token 序列」，动作是「下一个 token」。马尔可夫性靠把历史塞进上下文来凑。

还有两个经常混的词：

  • 预测：策略 π 固定，估 V 或 Q。
  • 控制：同时改策略，找更好的 π。

Q-learning、PPO、GRPO 都是控制。价值函数经常只是控制的工具。

探索和利用

只挑当前看起来最好的动作（利用），可能永远看不到更好的路。必须偶尔试别的（探索）。

最常用：ε-greedy。以 1−ε 选 argmax Q，以 ε 均匀乱选。ε 随训练减小。策略梯度不靠 ε：π 本身是分布，采样就是探索；后面会加 entropy bonus 防止塌成一点。

回报与价值

从时刻 t 起的折扣回报：

G_t = r_{t+1} + γ r_{t+2} + γ² r_{t+3} + …
函数问的问题
状态价值 V_π(s)从 s 出发，一直跟 π，期望回报是多少
动作价值 Q_π(s,a)在 s 先做 a，之后跟 π，期望回报是多少
优势 A_π(s,a) = Q − V这个动作比「在 s 平均水平」好多少
PPO / GRPO 优化的是优势，不是原始奖励。奖励告诉你发生了什么；优势告诉你这个动作该被加强还是削弱。组内相对分数（GRPO）只是估计 A 的一种办法。

关系：V(s) = Σ_a π(a|s) Q(s,a)。所以 A 对动作求期望是 0：好的动作正、差的负，方便当梯度权重。

Bellman：价值的递归

V_π(s) = E_π[ r + γ V_π(s') ]
Q_π(s,a) = E[ r + γ V_π(s') ]

最优策略把期望换成 max：

V*(s) = max_a Q*(s,a)
Q*(s,a) = E[ r + γ max_{a'} Q*(s',a') ]

状态能枚举时，直接解这个方程：

算法在干什么
策略评估π 固定，反复扫 Bellman，把 V_π 算准
策略改进对新的 V，取 π'(s) = argmax_a Q(s,a)
策略迭代评估 → 改进 → 再评估，直到 π 不变
值迭代跳过显式 π，直接对 Q 或 V 做 max 备份

状态一大，表格扫不动，就改成采样 + 函数近似，那就是深度 RL。

蒙特卡洛和 TD

不知道 P 时，用采样代替期望。

更新用什么特点
蒙特卡洛 (MC)整条轨迹走完才有的真实 G_t无偏，方差大，必须等到 done
时序差分 TD(0)一步备份 r + γ V(s')有偏（V 不准时），方差小，每步都能更

TD 目标里的 V 是自己估的，所以叫 bootstrap。PPO 里的 GAE 是 MC 和 TD 的插值：λ=1 接近 MC，λ=0 就是一步 TD。

SARSA 和 Q-learning

都是表格上的 TD 控制，差在备份时「下一步动作」怎么取：

SARSA:      Q(s,a) ← Q(s,a) + α [ r + γ Q(s', a') − Q(s,a) ]   # a' ~ π，on-policy
Q-learning: Q(s,a) ← Q(s,a) + α [ r + γ max_{a'} Q(s',a') − Q ] # max，off-policy

SARSA 学的是「我真的会执行的 π」（含探索）；Q-learning 学的是贪心最优 Q，行为策略可以是 ε-greedy。DQN 就是 Q-learning 换成神经网络。

两条家族

家族学什么策略怎么来代表
基于价值Q 或 Vgreedy / ε-greedyQ-learning、DQN
基于策略直接参数化 π_θ采样 π_θREINFORCE、PPO、GRPO
Actor-Criticπ 和 V 一起采样 π，V 当 baselineA2C、带 value head 的 PPO

语言模型几乎全是策略梯度：词表 ~10⁵，Q 表不现实；生成是序列决策，自然是 π(token | prefix)。

On-policy 和 off-policy

  • On-policy：用来学习的数据必须来自当前策略。PPO、GRPO 都是。采一批、更新几步、丢掉，再采。
  • Off-policy：可以用旧策略甚至别的策略的数据。DQN 的 replay、DPO 的偏好对更接近这条。

On-policy 所以才有 importance ratio：π_new(a|s) / π_old(a|s)。旧数据要拿来多更新几次，必须用这个比把分布校正回来。LLM 训练里分母 π_old 的 logprob 往往是 rollout 引擎算的，分子是训练引擎重算的——两边不一致，ratio 就是垃圾。这是系统页的伏笔。
